01 / About Sobre mí

My path into software didn't start in a bootcamp. It started in a public hospital, writing code that kept critical operations running — and grew into designing distributed systems for an entire province. Over 16+ years, I've built software across healthcare, fintech, and enterprise SaaS.

Mi camino en el software no empezó en un bootcamp. Empezó en un hospital público, escribiendo código que mantenía operaciones críticas en funcionamiento — y creció hasta diseñar sistemas distribuidos para toda una provincia. En más de 16 años, construí software en salud, fintech y SaaS empresarial.

Looking back, I've spent my career on one problem: making systems keep an honest map of themselves. First through interoperability contracts — HL7 FHIR, so every hospital system could trust what another one said. Now through verifiable memory for AI agents — because an agent with a wrong map of your codebase is confidently wrong at scale.

Mirando hacia atrás, pasé mi carrera trabajando sobre un mismo problema: que los sistemas mantengan un mapa honesto de sí mismos. Primero con contratos de interoperabilidad — HL7 FHIR, para que cada sistema hospitalario pudiera confiar en lo que decía otro. Hoy con memoria verificable para agentes de IA — porque un agente con un mapa equivocado de tu código se equivoca con total confianza, y a escala.

Open source · AI infrastructure · 2026

Long Horizon

A verified map of every project — and a live view of what your AI actually reads from it. Un mapa verificado de cada proyecto — y una vista en vivo de lo que tu IA realmente lee de él.

ProblemProblema
An AI agent with a wrong map of a codebase is confidently wrong at scale. And a map auto-generated from the code is ~90% right — which is worse than nothing: you stop verifying, and the wrong 10% is where you get hurt.
Un agente de IA con un mapa equivocado del código se equivoca con total confianza, y a escala. Y un mapa autogenerado desde el código acierta ~90% — lo cual es peor que nada: dejás de verificar, y el 10% equivocado es donde te lastimás.
DecisionDecisión
Curated, in-repo knowledge in seven fixed rooms, with every note anchored to real file paths so staleness is provable. doctor verifies the map and fails CI when it's wrong; scan bootstraps from verifiable facts and refuses to invent what it can't derive.
Conocimiento curado dentro del repo, en siete "habitaciones" fijas, con cada nota anclada a rutas reales para que lo desactualizado sea demostrable. doctor verifica el mapa y rompe el CI cuando está mal; scan arranca desde hechos verificables y se niega a inventar lo que no puede deducir.
Why it holdsPor qué funciona
A VS Code extension proxies the agent's stdio and shows, live, what it retrieves and what it costs — so you can see whether the map is actually used instead of hoping it is.
Una extensión de VS Code hace de proxy del stdio del agente y muestra en vivo qué recupera y cuánto cuesta — así ves si el mapa se usa de verdad en lugar de esperar que se use.

02
Open source · Agent learning · 2026

Memento

Your agent wakes up with amnesia every session. Memento is its system of tattoos. Tu agente se despierta con amnesia en cada sesión. Memento es su sistema de tatuajes.

ProblemProblema
Teams "teach" agents by appending rules to prompts after every bug. Every rule loads on every run, nothing is ever pruned, and adherence degrades. Accumulation without curation isn't learning — it's hoarding.
Los equipos "enseñan" a los agentes agregando reglas al prompt después de cada bug. Cada regla se carga en cada ejecución, nada se poda nunca, y la adherencia se degrada. Acumular sin curar no es aprender — es juntar cosas.
DecisionDecisión
Implements ACE — Agentic Context Engineering (Stanford & SambaNova, 2025) as a Recall → Learn → Curate loop, but on a memory palace instead of the paper's single scored playbook: lessons come from real outcomes, live where the concept lives, and are retrieved by context.
Implementa ACE — Agentic Context Engineering (Stanford y SambaNova, 2025) como un ciclo Recordar → Aprender → Curar, pero sobre un memory palace en lugar del playbook único con puntaje del paper: las lecciones salen de resultados reales, viven donde vive el concepto y se recuperan por contexto.
Why it holdsPor qué funciona
Lessons are Markdown in the repo — reviewable in PRs, mergeable in git — and anchored to code, so when the code moves the lesson is flagged instead of silently rotting. Search runs on local embeddings: zero per-query LLM cost.
Las lecciones son Markdown en el repo — revisables en PRs, mergeables en git — y ancladas al código, así que cuando el código cambia la lección queda marcada en lugar de pudrirse en silencio. La búsqueda usa embeddings locales: cero costo de LLM por consulta.

03
Open source · Multi-agent QA · 2026

QA Office

A team of QA agents that test like humans — and escalate the hard calls to one. Un equipo de agentes de QA que prueban como humanos — y le escalan las decisiones difíciles a uno.

ProblemProblema
Manual regression against spreadsheets of test cases doesn't scale, and fully autonomous agents can't be trusted with judgment calls.
La regresión manual contra planillas de casos de prueba no escala, y no se le puede confiar el criterio a agentes totalmente autónomos.
DecisionDecisión
A boss agent plans and hands out test cases; tester agents drive real browsers with Playwright, ask colleagues or the boss, and escalate important decisions to a human, blocking until answered. The UI only renders an event stream — it knows nothing about QA.
Un agente jefe planifica y reparte los casos; los agentes testers manejan navegadores reales con Playwright, consultan a sus compañeros o al jefe y escalan las decisiones importantes a un humano, bloqueándose hasta tener respuesta. La UI solo renderiza un flujo de eventos — no sabe nada de QA.
SecuritySeguridad
Least privilege by design: agents never get a shell, data access goes through an allowlisted CLI tool, and every connector except two read-only spreadsheet tools is denied.
Mínimo privilegio por diseño: los agentes nunca tienen shell, el acceso a datos pasa por una herramienta de CLI con allowlist, y se bloquean todos los conectores salvo dos de solo lectura para planillas.

Open source · Code review · 2025

CodeReview MCP

Model-agnostic automated PR review — Claude, Gemini or Codex. Code review automático de PRs, agnóstico del modelo — Claude, Gemini o Codex.

Reviews single or batched GitHub pull requests through the GitHub MCP server and posts the review back on the PR. Auto-detects whichever agent CLI is installed, validates every PR URL before a batch starts, uses one reusable review template, and supports GitHub App auth for organizations.

Revisa uno o varios pull requests de GitHub a través del servidor MCP de GitHub y publica la review en el PR. Detecta automáticamente qué CLI de agente está instalada, valida cada URL antes de arrancar un lote, usa una sola plantilla reutilizable y soporta autenticación con GitHub App para organizaciones.
