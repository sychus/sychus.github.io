Key Projects Proyectos Clave

Long Horizon · github.com/sychus/long-horizon · 2026

Open-source, verified project map for AI agents. Every note is anchored to real file paths so staleness is provable; doctor fails CI when the map is wrong and scan refuses to invent what it can't derive. A VS Code extension proxies the agent's stdio to show live what it retrieves and what it costs. TypeScript, MCP, MemPalace.

Mapa de proyecto verificado y open source para agentes de IA. Cada nota está anclada a rutas reales, así lo desactualizado es demostrable; doctor rompe el CI cuando el mapa está mal y scan se niega a inventar lo que no puede deducir. Una extensión de VS Code hace de proxy del stdio del agente y muestra en vivo qué recupera y cuánto cuesta. TypeScript, MCP, MemPalace.

Memento · github.com/sychus/memento · 2026

Learning architecture for AI agents implementing ACE (Agentic Context Engineering, Stanford & SambaNova 2025) as a Recall → Learn → Curate loop on a memory palace instead of a single scored playbook. Lessons come from real outcomes, live in the repo as reviewable Markdown, are anchored to code, and are retrieved by context with local embeddings (zero per-query LLM cost).

Arquitectura de aprendizaje para agentes de IA que implementa ACE (Agentic Context Engineering, Stanford y SambaNova 2025) como un ciclo Recordar → Aprender → Curar sobre un memory palace en lugar de un playbook único con puntaje. Las lecciones salen de resultados reales, viven en el repo como Markdown revisable, están ancladas al código y se recuperan por contexto con embeddings locales (cero costo de LLM por consulta).

QA Office · github.com/sychus/qa-like-humans · 2026

Multi-agent QA system on the Claude Agent SDK: a boss agent plans and assigns test cases, tester agents drive real browsers with Playwright and escalate judgment calls to a human. Least privilege by design — no shell for agents, allowlisted data tools, all other connectors denied.

Sistema de QA multi-agente sobre Claude Agent SDK: un agente jefe planifica y asigna los casos, los agentes testers manejan navegadores reales con Playwright y escalan las decisiones de criterio a un humano. Mínimo privilegio por diseño — sin shell para los agentes, herramientas de datos con allowlist y el resto de los conectores bloqueados.

CodeReview MCP · github.com/sychus/CodeReviewMCP · 2025

Model-agnostic automated PR review (Claude, Gemini, Codex) over the GitHub MCP server, with batch processing, URL validation and GitHub App auth for organizations.

Code review automático de PRs agnóstico del modelo (Claude, Gemini, Codex) sobre el servidor MCP de GitHub, con procesamiento por lotes, validación de URLs y autenticación con GitHub App para organizaciones.
